# Cybersports.live — Esports Live Tracker & Analytics

This is the original home for the neverfinished project:—.

## Overview

Cybersports.live is a state-of-the-art website that supplies up-to-date information about the world of the cybersports along with the live scoring, tournament schedules and data statistics of Counter-Strike 2 (CS2) and Dota 2.

## Key Features

- ⚡ Up-to-the-minute updates of gamescore.

- Detailed player statistics (K/D, ADR, KAST, GPM, XPM).

- 🏆 The roster for any regular season or playoff tournament includes all participating teams/battles at the top or bottom; ie. who will fight for the crown or be defeated by the favorite to determine positions in the playoffs or standings.

- 🔮 Interactive match predition system.

- Complete bilingualin (Ukrainian&English).

Visit the platform: https://cybersports.live/
